What you can learn here

1. Models

`Category`, `Product`, `Order`, and `OrderItem` show relationships between tables.

2. Views

Each page has a view function that prepares data and sends it to a template.

3. Templates

Templates loop through products and categories using Django template tags.

4. Cart + Checkout

The cart uses Django sessions and checkout uses a simple form without authentication.

Learning roadmap

  • Start with the product list page to understand routing and filtering.
  • Add products to cart to see how session storage works.
  • Complete checkout to learn how forms create orders and order items.
  • Use the admin panel to edit products, stock, and order status.
  • Use order tracking by email to review saved customer orders without auth.
